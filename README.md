## Le client

**Soleil Bissap** est une petite entreprise de jus naturels basée à Cotonou, dirigée par Mme Houngbo. Elle lance un nouveau jus de **bissap au gingembre**.

## Le brief en bref

| Élément | Détail |
|---|---|
| Objectif | Faire connaître le nouveau jus de bissap au gingembre |
| Cible | Jeunes de 18 à 30 ans, surtout sur les réseaux sociaux |
| Style | Joyeux, frais et énergique, avec des illustrations plutôt que des photos |
| Budget | 800 000 FCFA, impression des affiches comprise |
| Délais | Première proposition en 2 semaines, livraison finale en 4 semaines |

### Règles de classement

- **Sources** : les fichiers qu'on peut encore modifier (fichiers vectoriels, projets d'origine).
- **Exports** : les fichiers finaux, au format et à la résolution adaptés (affiche en A3, visuels carrés pour les réseaux sociaux).
- **Noms de fichiers** : en minuscules, sans espaces, avec des tirets (par exemple `rapport-de-projet.docx`).
- **Versions** : chaque modification importante est enregistrée par un commit Git avec un message clair.
- **Sauvegarde** : le dépôt GitHub sert de sauvegarde en ligne.
